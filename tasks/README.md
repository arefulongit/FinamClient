# Task Tracker — Beholder

> Данные каждой задачи хранятся в отдельном каталоге `TASK-NNN/` (файл `task.md` + любые приложения). 

> Статусы: `[ ]` open · `[-]` in progress · `[x]` done · `[!]` blocked


## Правила ведения

1. **Новая задача**: скопировать шаблон из `_TEMPLATE/task.md` в новый каталог `Task/TASK-NNN/task.md`, заполнить поля.
2. Номер следующей задачи = max(NNN)+1.
3. **Статус** меняется в `task.md` самой задачи.
4. Любые заметки/скриншоты/логи по задаче кладутся в каталог самой задачи.
5. Открытой считается задача со статусом `[ ]` или `[-]`. В сессии берём первую открытую по порядку.
6. В `task.md` НЕ заполняются секции `План / шаги`, `Затрагиваемые файлы`, `Лог` — их ведёт **TAUSIK** (`.tausik/tausik task plan/step/log`).
